# 🧭 Ninobyte CloudOps Lab

**AWS-native training labs for AI CloudOps, security, and governance.**

Ninobyte CloudOps Lab develops governed, evidence-based training environments for professionals learning how to build, operate, secure, audit, and explain AWS AI workloads. Our labs favor depth over breadth: real AWS services, real guardrails, and real proof of work — not passive video courses or unverifiable certificates. Every program is built around controlled sandboxes, documented governance, and portfolio-ready evidence. We are deliberately AWS-first, because durable cloud and AI skills come from working inside one cloud deeply rather than skimming many. This is the applied training arm of Ninobyte's AI-native direction.

> **Build. Operate. Secure. Govern AWS AI systems.**

The organization's product repositories are **private by design**. Public visibility is reserved for this profile.

- **For:** the internal team building the Security & Governance product.

### `ai-security-governance-lab-student-template` &nbsp;·&nbsp; 🔒 Private template
- **Contains:** a sanitized, portfolio-safe learner workspace — ticket-based AWS AI security practice, evidence and reflection structure, and proof-pack scaffolding.
- **For:** enrolled learners working through the Security & Governance Lab.
- **Status:** private, beta-ready; no public release.
- **Does not contain:** solution guides, instructor notes, credentials, or AWS provisioning.

> 🚫 Internal solution guides, instructor answer keys, and AWS account details are never published.

*Additional learner templates — for example, a future CloudOps student workspace — are planned but do not yet exist.*

## Operating principles

- **AWS-first depth** over shallow multi-cloud theory.
- **Evidence before claims** — work is shown, not asserted.
- **Governance before deployment** — guardrails precede access.
- **Safe sandboxes** over uncontrolled access.
- **Proof packs** over passive certificates.
- **No AWS execution before cost and safety gates** are validated.
- **No public leakage** of internal or learner materials.
